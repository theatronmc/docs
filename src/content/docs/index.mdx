Theatron connects a browser workspace to a Minecraft Paper server. This documentation site is being prepared alongside the open-source release.

**The self-hosted release is not available yet.** There is no supported installation command, downloadable plugin, or published product license in the public repositories today. See [release status](/project-status/) for what exists and what is planned.

When the release is ready, this site will cover installation, upgrades, backups, creating worlds and Flows, building extensions, and connecting a Paper server. Commands and compatibility information will be tied to tested releases.
