---
title: Release status
description: What is public today and what is still being prepared.
---

Theatron is a working hosted product. Apeyron is preparing the core for a useful self-hosted release. The [public core repository](https://github.com/theatronmc/theatron) currently contains scope documentation only; product source and installation artifacts have not been published.

The planned self-hosted stack will let operators create and publish their own NPCs, quests, shops, items, Flows, and extensions without an Apeyron account. Apeyron Cloud will use the same public core. The optional Central store and payment service will remain separate.

This is a **target architecture**, not a statement that those deployment paths already work. Installation, security, maintenance, backup, upgrade, and extension guides will be added here when they can be verified against a release.

For product capabilities available today, visit the [Theatron website](https://www.theatronmc.com/). The [GitHub organization](https://github.com/theatronmc) lists the repositories being prepared for the open-source ecosystem.
